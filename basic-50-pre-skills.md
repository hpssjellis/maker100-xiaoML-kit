# Maker100: 50 Entry-Level Skills & Prerequisites

| # | Category | Skill Description |
| :--- | :--- | :--- |
| 1 | **Digital Literacy** | Ability to download and install software (like Arduino IDE) on a laptop. |
| 2 | **Digital Literacy** | Familiarity with folder structures and organizing project files. |
| 3 | **Digital Literacy** | Knowing how to copy, paste, and edit text within a code editor. |
| 4 | **Digital Literacy** | Basic understanding of "Open Source" (e.g., using GitHub to find code). |
| 5 | **Hardware** | Distinguishing between USB-C, Micro-USB, and USB-A cables. |
| 6 | **Hardware** | Understanding the concept of "Ground" in a battery-powered system. |
| 7 | **Hardware** | Ability to use a screwdriver and basic hand tools safely. |
| 8 | **Math** | Basic algebra for calculating ratios and simple equations ($V=IR$). |
| 9 | **Math** | Understanding 2D coordinate systems (X and Y axes). |
| 10 | **Math** | Basic understanding of percentages (used in ML confidence scores). |
| 11 | **Logic** | Understanding "If-Then" logic (e.g., If it rains, then use an umbrella). |
| 12 | **Logic** | Ability to follow a multi-step "recipe" or set of assembly instructions. |
| 13 | **Circuits** | Knowing that a circuit must be a "closed loop" to function. |
| 14 | **Circuits** | Identifying the difference between a battery and a sensor. |
| 15 | **Circuits** | Understanding that red wires usually mean positive and black mean negative. |
| 16 | **Electronics** | Basic awareness that microcontrollers (MCUs) are the "brains" of robots. |
| 17 | **Electronics** | Knowing that too much voltage can permanently damage a chip. |
| 18 | **Internet** | Ability to use a search engine to troubleshoot an error message. |
| 19 | **Internet** | Knowing how to connect a device to a local WiFi network. |
| 20 | **Physics** | Basic understanding of friction and gravity's effect on movement. |
| 21 | **Physics** | Concept of "Force" and how it relates to motors or levers. |
| 22 | **Physics** | Understanding that light and sound are forms of data. |
| 23 | **Design** | Ability to sketch a rough idea of a project on paper. |
| 24 | **Design** | Understanding that the first version of a project is a "prototype." |
| 25 | **Communication** | Ability to work with a partner and share technical tasks. |
| 26 | **Communication** | Knowing how to take a clear photo of a circuit for documentation. |
| 27 | **Safety** | Identifying a "hot" soldering iron and knowing not to touch the tip. |
| 28 | **Safety** | Awareness of lithium battery safety (not puncturing or shorting). |
| 29 | **Organization** | Keeping small parts (screws, LEDs) in labeled bins or trays. |
| 30 | **Creativity** | Willingness to "break" code to see what happens. |
| 31 | **Software** | Knowing how to select a "COM Port" or "Serial Port" in a menu. |
| 32 | **Software** | Understanding that code is case-sensitive (capital letters matter). |
| 33 | **Machine Learning** | Basic concept that AI is trained on data, not programmed with rules. |
| 34 | **Machine Learning** | Knowing that a camera sees pixels, not actual "objects." |
| 35 | **Media** | Ability to record a short video using a smartphone. |
| 36 | **Media** | Understanding how to resize an image so it isn't too large for a web upload. |
| 37 | **Components** | Identifying a Breadboard and its internal connection rows. |
| 38 | **Components** | Knowing what an LED (Light Emitting Diode) is. |
| 39 | **Components** | Distinguishing between a Button (Input) and a Light (Output). |
| 40 | **Manufacturing** | Basic concept of "Additive" (3D printing) vs "Subtractive" (cutting). |
| 41 | **Manufacturing** | Measuring objects accurately using a ruler in millimeters (mm). |
| 42 | **Robotics** | Understanding that a "Sensor" detects the world and an "Actuator" changes it. |
| 43 | **IoT** | Awareness that devices can talk to each other without wires. |
| 44 | **Ethics** | Understanding privacy concerns when using cameras in public. |
| 45 | **Ethics** | Respecting "Intellectual Property" and giving credit to code authors. |
| 46 | **Resilience** | Being okay with a project not working on the first try. |
| 47 | **Resilience** | Willingness to read "ReadMe" files or documentation. |
| 48 | **Spatial Reasoning** | Visualizing how a 3D object looks from different angles. |
| 49 | **Tooling** | Knowing how to use "Zip Ties" or tape for cable management. |
| 50 | **Curiosity** | Asking "How does this work?" when looking at a remote control or toy. |
